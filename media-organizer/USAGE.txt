Media Renamer - Usage Commands
===============================

Automatically renames and organizes movies and TV shows from downloads.
(How it decides things, and what it will never do: see HOW-IT-WORKS.txt.)

BACKGROUND SERVICE (runs 24/7, starts at boot):
-----------------------------------------------
systemctl status tvclone-organizer         # check status
sudo systemctl restart tvclone-organizer   # restart
sudo systemctl stop tvclone-organizer      # stop
sudo systemctl start tvclone-organizer     # start

The Organizer page in ChocheyTV shows the same state, what it is doing right now, what needs
review, and has a "Restart organizer" button.

Log:     media-organizer/media-organizer.log   (inside the TV-Clone-prod folder)
Status:  data/organizer-status.json


SETUP (one-time):
-----------------
cd media-organizer
pip3 install --break-system-packages -r requirements.txt
(put OMDB_API_KEY=... in media-organizer/.env)


RUN ONCE (process new downloads):
---------------------------------
python3 movie_renamer.py


DRY RUN (preview without moving):
---------------------------------
python3 movie_renamer.py --dry-run


RUN IN WATCH MODE (auto every 30 seconds):
------------------------------------------
python3 movie_renamer.py --watch
(The service does this. Don't run a second copy by hand while it is running.)


RENAME EXISTING LIBRARIES:
--------------------------
# Scan and rename both movies and TV at once:
python3 movie_renamer.py --all

# Preview first (dry run):
python3 movie_renamer.py --all --dry-run

# Movies only:
python3 movie_renamer.py --library

# TV only:
python3 movie_renamer.py --library-tv


STOP WATCH MODE:
----------------
Press Ctrl+C


TESTS:
------
cd media-organizer
python3 -m unittest discover -s . -p "test_*.py"
(Offline: no network, no real media. They never write to the real log or status file.)


HOW IT WORKS:
-------------
Movies:   /mnt/media/Share -> /mnt/media/Movies/Title (Year)/Title (Year).ext
TV Shows: /mnt/media/Share -> /mnt/media/TV/Show Name (Year)/Season XX/Show Name - S01E01 - Episode.ext
TV bonus: /mnt/media/Share -> /mnt/media/TV/Show Name (Year)/Extras/...

Auto-detection:
- If filename has S01E01, SxxExx, season/episode info -> TV show
- Otherwise -> Movie


MERGERFS STORAGE:
-----------------
All the USB drives are combined into a single /mnt/media mount using mergerfs.
The drives auto-mount on boot via /etc/fstab. mergerfs does NOT modify the
underlying drives - it provides a unified view on top of them.

If a TV show or movie already exists on a drive, new episodes/seasons are
automatically placed on that same drive (epmfs policy). New content goes
to the drive with the most free space.


CONFIGURATION:
--------------
Edit config.py (or set the ORGANIZER_ variable in media-organizer/.env) to change:
- SOURCE_DIR: Where downloads come from (/mnt/media/Share)
- MOVIE_DEST_DIR: Movie destination (/mnt/media/Movies)
- TV_DEST_DIR: TV destination (/mnt/media/TV)
- POLL_INTERVAL: How often to scan in watch mode (default: 30 seconds)
- FILE_EXTRAS: File TV bonus videos under <Show>/Extras (default: on; ORGANIZER_FILE_EXTRAS=0 turns it off)
Restart the service after changing any of them.
